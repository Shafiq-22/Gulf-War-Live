If feeds show UNAVAILABLE
The most common cause is opening the file directly from your desktop (file://). Browsers block all cross-origin network requests from file origins as a security policy — no proxy can work around this.

Solution: Serve the file from a local web server:

python3 -m http.server 8080

Run that in the folder containing index.html, then open http://localhost:8080 in your browser. Everything will work immediately.
